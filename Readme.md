# S3-TP1 — Ressources

  AUCUN rapport configuré). À utiliser si votre propre projet OrderFlow n'est pas exploitable.

  - Python : `pip install -r requirements-dev.txt` puis `pytest`
  - JavaScript : `npm ci` puis `npm test`
  - Java : `mvn test`
